# Phase 4: Orchestrator

Integrated Phase-4 redemption circuit of the Noir / UltraHonk implementation.
See `../docs/phase4_orchestrator.md` for the processing flow and
`../../docs/protocol_specification.md` for the normative relations.

Invalid conditions (invalid signature, key not in the registry, expired
prescription, slot ≥ threshold, tampered prescription fields, off-curve points,
out-of-range scalar) are hard constraint failures: no proof can be generated.

## Inputs

* `Prover.toml` and `tests/positive/*.toml`, `tests/negative/*.toml` are
  generated by `circom/scripts/build_canonical_fixture.js` from the single
  canonical fixture shared with the Circom implementation.
* `tests/historical/pre_alignment_depth4/` contains pre-alignment vectors kept
  for reference; they are not executed.

## Tests

```bash
nargo test                              # isolated signature-verifier tests
cd tests/scripts
./run_positive_suite.sh                 # TV-001..TV-005
./run_negative_suite.sh                 # NT-001..NT-020
```

The positive suite checks the public outputs `[C, N]` against
`testdata/kat/canonical_fixture.json`, generates an UltraHonk proof, verifies
it, and checks that tampered public inputs do not verify. The negative suite
requires every vector to fail a circuit constraint.
